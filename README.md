# 🎨 Генератор афиш «Декада приемов граждан»

Веб-приложение на чистом HTML/CSS/JS для генерации афиш в высоком качестве (PNG)
для публикации в социальных сетях (ВКонтакте). Позволяет мгновенно получать
изображения в двух форматах: десктопном (1080×1350) и квадратном для ленты (1080×1080).

## 📁 Структура проекта

~~~text
afisha-samara-DD.MM-DD.MM/
├── index.html                # Весь проект: HTML + CSS + JS в одном файле
├── README.md                 # Эта инструкция
└── assets/
    └── images/
        ├── background.jpg    # Фоновое фото района/города
        ├── logo-er.png       # Логотип «Единая Россия» (прозрачный фон)
        └── gerb-sovetsky.jpg # Герб района (или иной символ)
~~~

## 🚀 Как запустить локально

Функция скачивания PNG использует библиотеку html2canvas и требует локального
HTTP-сервера (иначе браузер блокирует чтение изображений из-за политики CORS).

~~~bash
python3 -m http.server 8080
~~~

Затем открой в браузере: http://localhost:8080

> ⚠️ Не закрывай окно терминала, пока работаешь с афишей.
> Для остановки сервера нажми Ctrl+C.

## 💾 Как сохранить афишу

1. В правом верхнем углу выбери режим:
   - 🖥️ Десктоп — 1080×1350 px
   - 📱 Мобильный — 1080×1080 px (квадрат для ленты ВК)
2. Нажми **📦 Скачать оба** (или **💾 Скачать текущий**).
3. Через 1–2 секунды файлы afisha-desktop.png и afisha-mobile.png
   сохранятся в папку «Загрузки» в двойном качестве (scale 2x).

## ✏️ Что менять при новой декаде

Открой index.html в любом редакторе (nano, gedit, VS Code) и поправь:

- даты декады в блоке class="dates";
- темы и даты приёмов в блоке class="schedule" (поля schedule-date и schedule-desc);
- контакты в блоке class="footer-contacts";
- при необходимости — надписи в шапке (class="org-info", class="slogan-right").

Все размеры и вёрстка подстраиваются автоматически, картинка не «поплывёт».

## 🔄 Как создать проект для следующей декады (шаблон)

1. Скопируй текущий проект и переименуй по датам новой декады:
   ~~~bash
   cd ~/projects
   cp -r afisha-samara-25.11-4.12 afisha-samara-01.03-10.03
   cd afisha-samara-01.03-10.03
   ~~~
2. Замени файлы в assets/images/ на новые, сохранив те же имена.
3. Отредактируй index.html по списку выше.
4. Запусти сервер и сделай PNG.

## ⚙️ Технологии

HTML5 · CSS3 (Flexbox + Grid) · JavaScript ES6+ · html2canvas 1.4.1 (CDN) ·
Google Fonts (Montserrat, Roboto).

## 📌 Примечания

- Стили и скрипты встроены в index.html для портативности.
- Для работы без интернета скачай html2canvas.min.js в assets/js/ и поправь
  путь в теге script.
- Имена файлов в assets/images/ фиксированы — не переименовывай их, иначе
  афиша не соберётся.
